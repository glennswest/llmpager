Lesson two: the memory hierarchy is the product. Bypassing the operating system's file cache is right when the model exceeds RAM, and exactly wrong when it fits; flipping that one flag was the single biggest win. Allocation granularity silently wasted sixty percent of our cache memory until an impossible out of memory error exposed it. Overlap beat raw bandwidth every time. And caches must age, because what's hot drifts. The bottleneck never disappears, it migrates, and only measurement finds where it went.
