The source is about five thousand lines of Rust and CUDA, in five crates — five building blocks. A file format library, the pager that moves weights, a converter that repackages downloaded models in twenty-one seconds, a runner that generates text, and a web server that answers requests like any AI API. One detail worth noting: nothing here needs the CUDA toolkit installed at runtime — the GPU kernels are compiled to portable form at build time, and the driver does the rest. It's Apache-licensed, on GitHub, with deb and rpm packages for Debian and Fedora.
