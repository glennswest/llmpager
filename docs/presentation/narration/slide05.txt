So here's the idea. Keep the shared core of the model — the parts every token needs — resident in GPU memory. Stream the routed experts from the SSD on demand, and cache the frequently-used ones in a per-layer cache. The pipeline runs left to right: the router picks experts, the cache answers instantly for hits, misses are read from disk into pinned memory and copied to the GPU asynchronously, and the expert math runs as soon as its weights land. The trick is that fetching the next folder happens while you're still reading the current one.
