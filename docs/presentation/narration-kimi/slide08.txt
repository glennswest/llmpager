Now the war stories. Kimi ships a tick token tokenizer, which none of the standard Rust libraries can load. So I built a tokenizer dot jason with the official converter, and patched in two hundred fifty six special tokens with explicit I Ds. And then found something ugly. The config file disagrees with the model's own tokenizer about the I D of the I M middle token. One says one six three five nine eight. The other says one six three six oh one. If you trust the config, every conversation you send the model is subtly malformed, and nothing ever crashes. Trust the tokenizer. Verify byte for byte.
