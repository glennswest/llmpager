The architecture hasn't changed since day one. A token hits the router, which picks eight experts for the layer. The cache check happens in VRAM. Hits are free. Misses go to the payjer, which reads the expert from disk with direct I O, stages it through pinned memory, and copies it up to the card while compute continues. Least frequently used experts get evicted. The point of this slide is the last line. The exact same engine that runs a thirty billion parameter model at forty one tokens per second is running a one trillion parameter model. Only the scale changed.
